# Prisma ORM 7

Models live in `schema.prisma`. Set `DATABASE_URL` in `.env` to your PostgreSQL connection string.

Run `bun run db:generate` after schema changes. Import `db` from `prisma/db.ts` in server code and use Prisma Client methods such as `db.user.findMany()` or `db.user.create({ data: ... })`.

Run `bun run db:migrate --name <migration-name>` when ready to apply a schema change to your development database. No database migrations were applied during the switch from Prisma 8.

The generated client lives in `prisma/generated/client` and is regenerated by `bun install`.
